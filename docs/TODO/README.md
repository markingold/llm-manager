# TODO — Ecosystem Action Items

This folder contains action items generated by ecosystem-wide audits,
Copilot prompt scans, and manual planning from 2bananas-standards.

## Convention
- Files are named: `<topic>-<YYYY-MM-DD>.md` (e.g., `logging-audit-2026-03-28.md`)
- Each file has a `## Status` section: OPEN, IN-PROGRESS, DONE
- Completed items can be archived to `docs/TODO/archive/`
- Generated by prompts in `/srv/2bananas/projects/2bananas-standards/.github/prompts/`
